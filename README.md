# 党建理论学习文章清单

每天定时从几个公开的党建、理论学习网站首页抓取文章的**标题、链接和日期**，生成 `feed.json`，供「党小务工作助手」的「理论学习」栏目读取。

- 只收标题和链接，不收正文；阅读请点链接到原网站。
- 来源：求是网、共产党员网、人民网理论频道、人民网党建频道、人民网观点频道。
- 每条保留 60 天，每个来源最多 40 条。
- 某个网站某次没抓到时，保留它上次的条目，`sources` 里会注明。

`feed.json` 的格式：`items` 里每条是 `{t: 标题, u: 链接, d: 日期, s: 来源 id}`，`sources` 是各来源的名称和本次抓取情况，`updated` 是内容最后一次变化的时间。
